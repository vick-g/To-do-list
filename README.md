# 📝 To-do List Interativa

Um aplicativo web moderno e responsivo de gerenciamento de tarefas desenvolvido para o dia a dia, construído com tecnologias web fundamentais.

## 🚀 Funcionalidades

- **Adição de Tarefas:** Insira novas tarefas facilmente pelo campo de texto.
- **Níveis de Prioridade:** Classifique as tarefas entre **Urgente** e **Adiável** com indicadores visuais personalizados.
- **Marcação de Conclusão:** Marque ou desmarque tarefas como concluídas com um clique (com efeito de texto riscado).
- **Contadores em Tempo Real:** Acompanhe o total de tarefas, quantas estão pendentes e quantas já foram concluídas.
- **Persistência de Dados (Local Storage):** Suas tarefas ficam salvas no navegador, garantindo que não se percam ao atualizar a página.
- **Modo Escuro (Dark Mode):** Alterne facilmente entre o tema claro e o escuro com um clique.
- **Atalho com Tecla Enter:** Adicione tarefas rapidamente pressionando "Enter" no teclado.
- **Exclusão de Itens:** Remova tarefas indesejadas individualmente.

## 🛠️ Tecnologias Utilizadas

Este projeto foi desenvolvido utilizando:

- **HTML5:** Estrutura semântica da página.
- **CSS3:** Estilização responsiva, variáveis de tema e animações suaves.
- **JavaScript (ES6+):** Manipulação do DOM, tratamento de eventos e gerenciamento do Local Storage.
